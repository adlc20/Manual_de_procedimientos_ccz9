Convenios de financiación y refinanciación de adeudos por tributos y precios

- Mediante este trámite podés solicitar un convenio para financiación y refinanciación de adeudos por tributos y precios, y financiación de deudas gestionadas judicialmente.

- Para trámite web Para este caso las cuentas no deben estar cerradas y no deben presentar traba de pago, juicio, convenio vigente (al día o atrasado), liquidaciones especiales (IPC o Decreto 36.045) o incluidas en el clearing, siempre que el saldo deudor sea igual o mayor a una unidad reajustable.

INSTRUCCIONES

- Este trámite se puede realizar de dos formas:

- Vía online : Escanee el QR, y inicie el tramite vía web

- Vía presencial : Requiere de agenda previa

- Se puede agendar llamando al 19503000.
